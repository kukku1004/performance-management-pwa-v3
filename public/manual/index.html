Chapter 01

어떤 파일부터 준비하나요?

성과는 평가 PDF가 가장 정확하고, 직급·연차·교육 같은 인사정보는 개인 인사기록카드 Excel을 우선 사용합니다.

가져오기 우선
PDF

평가 리포트 PDF

성과등급, 과제, 가중치, 평가 코멘트의 기준 자료입니다.

XLS

인사기록카드 Excel

직급, 연차, 발령, 교육, 경력, 상벌 정보를 가져옵니다.

5Y

기존 시뮬레이션 Excel

앞선 자료에 값이 없을 때만 5개년 이력의 보조 자료로 사용합니다.

평가 PDF›팀원 관리 정보›기존 Excel
체류 값팀원 관리의 연차를 우선 적용합니다. 기존 Excel 값을 사용하면 확인 필요 안내가 표시됩니다.
Chapter 02

평가 리포트 PDF 준비

인사평가 시스템에서 팀원별 리포트를 열고 PDF로 저장합니다.

성과 정보 1순위
1

팀원 평가 리포트 열기

인사평가 시스템 → 인사평가 → 평가 리포트에서 대상 팀원의 리포트 버튼을 누릅니다.

인사평가 · 평가 리포트
2

팀원 화면에서 프린트 선택

이름과 평가기간을 확인하고 오른쪽 위 프린트 버튼을 눌러 PDF로 저장합니다.

팀원별 평가 결과
파일명팀원 이름과 평가기간을 유지하면 여러 파일을 한 번에 올려도 정확하게 연결됩니다.
Chapter 03

인사기록카드 Excel 준비

개인 인사기록카드는 인사·성장 정보의 1순위이며 다른 평가 파일이 임의로 덮어쓰지 않습니다.

인사 정보 1순위
1

인사기록카드 출력 열기

ehr.osstem.com → 인사관리 → 인사기본에서 인사기록카드출력을 누릅니다.

e-HR · 인사기본
2

저장 형식에서 XLS 선택

프린트 팝업 상단의 저장 아이콘을 누르고 초록색 XLS를 선택합니다.

인사카드 · 내보내기
보호 원칙인사기록카드에서 가져온 값은 사용자가 직접 수정할 때만 변경됩니다.
Chapter 04

여러 파일을 한 번에 올리기

앱 상단의 빠른 시작에서 PDF와 Excel을 함께 선택하고 파일별 팀원 이름을 확인합니다.

여러 파일 가능
1

빠른 시작 → Excel로 시작

업로드 영역을 누르거나 준비한 파일을 한 번에 끌어다 놓습니다.

2

연결 결과 확인

추가·업데이트·확인 필요 건수와 팀원 이름을 확인합니다. 동명이인은 사번도 확인하세요.

3

코멘트 선택

체크한 코멘트만 `코멘트만 모아보기`에 저장되며 면담 기록과 분리됩니다.

평가과제·등급·가중치→평가결과와 개인 PDF
성장발령·교육·경력·상벌→보조지표와 산정 근거
승진최근 5개년 평가→점수와 승진 가능 여부
면담선택한 평가 코멘트→코멘트 기록으로 별도 보관
Chapter 05

평가와 면담 진행 순서

가져온 데이터는 두 업무 흐름에 자동 연결되며 같은 정보를 다시 입력하지 않습니다.

성과평가

과제·팀원 확인›평가하기›결과 확인›고과 확정›Excel·개인 PDF

팀원 관리와 면담

팀원 선택›이전 성과›승진 시뮬레이션›면담 준비›일정·면담 기록
구분 저장직접 작성한 내용은 `면담 기록`, PDF에서 선택한 코멘트는 `코멘트만 모아보기`에서 관리합니다.
